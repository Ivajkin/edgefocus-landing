Before you start

Do I need a card to register?+

No. Create an account with a username, email and password and start on Free. Paid plans are available separately in the app.

Do I have to move all my work at once?+

No. Start with one project and a few real tasks. Add more only when the workflow works for you.

What can the AI assistants do?+

Falco helps organize incoming work. EVA helps you analyze and discuss your workspace context. AI usage is limited by your plan; review suggestions before relying on them.

Can I connect my own tools?+

EdgeFocus has a REST API and an API skill for AI assistants. You configure access for the tools you choose.

REST API · EdgeFocus API Skill

Where can I check how data is handled?+

Read the Trust Center for the published information about security, access controls and verification status.
